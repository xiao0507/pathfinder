# Pathfinder · 英语学习应用

一个**完全独立、不依赖任何平台**的英语学习网页应用。背词、阅读、口语、原著、台词、美文、写作一站完成，目标是顺利通过 12 月的考试，并一路提升到能畅快阅读英文原著、无字幕看剧。

| 模块 | 说明 |
| --- | --- |

## 🚀 如何使用（独立网址）

### 方式 A：直接打开
双击 `index.html` 即可使用全部内置内容（点词、翻译、朗读、背词、阅读等）。
> 手机“安装到桌面”和整章自动翻译等能力建议通过下面的网址方式获得。

### 方式 B：部署成独立网址（推荐，可在手机上安装）
把本文件夹整体上传到任意静态托管，即可获得一个**属于你自己的网址**，免费且与扣子无关：

- **GitHub Pages / Cloudflare Pages / Vercel / Netlify**：把整个文件夹拖上去即可。
- 部署后在手机浏览器（Chrome / Safari / Edge）打开网址 → 菜单里选
  **“添加到主屏幕 / 安装应用”**，它就会像 App 一样出现在桌面，全屏运行、可离线。

电脑与手机均已适配，排版自适应。

## 🎤 录音说明（重要）

录音功能依赖浏览器的语音识别，请注意：

1. 请用 **Chrome / Edge / Safari** 打开；
2. 第一次录音时浏览器会弹出麦克风授权，请点「允许」；
3. **部署到 https 网址后录音最稳定**；直接双击 `index.html`（本地文件）时，部分浏览器会限制录音；
4. 若录音无反应，先到「设置 → 麦克风/录音自检」点「测试麦克风」，可直接看到是权限问题还是浏览器问题；
5. 操作方式：点 🎤 开始录音（按钮变为 ⏹️），**再点一次 ⏹️ 才停止**，停止后自动发送，可切换中/英文识别。
