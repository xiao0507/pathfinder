# Pathfinder · 英语学习应用

一个**完全独立、不依赖任何平台**的英语学习网页应用。背词、阅读、口语、原著、台词、美文、写作一站完成，目标是顺利通过 12 月的考试，并一路提升到能畅快阅读英文原著、无字幕看剧。

## ✨ 功能一览

| 模块 | 说明 |
| --- | --- |
| 🏠 首页 | 连续天数、待复习提醒、今日学习路线 |
| 🔤 单词学习 | **句子记忆 + 段落记忆**，2300+ 精选词（音标 / 双释义 / 例句 / 短语）；点“学会了，下一个”，按**遗忘曲线（间隔重复算法）**自动安排复习，到期提醒，新词源源不断 |
| 📖 短篇阅读 | 多篇双语短文，任意词点击查义、听发音；附**高频名词短语库**，可刷新 |
| 🎙️ 口语对话 | **美式发音**；24 个推荐场景模板 + 自由对话；点麦克风开始、**再点一次才停止**；支持**中文自动转英文**；可一键清空对话缓存 |
| 🎬 影视台词 | 无视频，经典台词 + 翻译，作品筛选，整批刷新，英文朗读 |
| 📚 英文原著 | **整本完整作品**（非片段），章节目录，每段中文翻译可展开/折叠，章末“生词框”，英文朗读 |
| ✨ 美文美句 | 中英对照美句，朗读，整批刷新 |
| ✍️ 写作练习 | 大量原创题目（思路点拨 + 高分表达 + 套用句型 + 范文 + 范文翻译 + 朗读），可刷新 |
| ⚙️ 设置 | 语速、翻译开关、缓存清理、进度重置 |

> 界面不出现任何 “CET / 六级” 字样。

## 🚀 如何使用（独立网址）

### 方式 A：直接打开
双击 `index.html` 即可使用全部内置内容（点词、翻译、朗读、背词、阅读等）。
> 手机“安装到桌面”和整章自动翻译等能力建议通过下面的网址方式获得。

### 方式 B：部署成独立网址（推荐，可在手机上安装）
把本文件夹整体上传到任意静态托管，即可获得一个**属于你自己的网址**，免费且与扣子无关：

- **GitHub Pages / Cloudflare Pages / Vercel / Netlify**：把整个文件夹拖上去即可。
- 部署后在手机浏览器（Chrome / Safari / Edge）打开网址 → 菜单里选
  **“添加到主屏幕 / 安装应用”**，它就会像 App 一样出现在桌面，全屏运行、可离线。

电脑与手机均已适配，排版自适应。

## 🔮（可选）接入大模型，解锁“无限刷新 + 真实对话”
应用默认内置大容量内容，可离线使用。若希望**无限生成新词/文章/题目/句子、与 AI 自由对话、中文转英文、整章高质量翻译**：

1. 打开应用 →「设置」
2. 填入任意 **OpenAI 兼容接口**的地址、API Key、模型名（如 `gpt-4o-mini`）
3. 保存后自动测试，成功即解锁。

Key 仅保存在你本机浏览器中，不上传任何第三方。未接入时，整章翻译使用免费翻译服务（需联网）。
